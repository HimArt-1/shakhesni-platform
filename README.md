# منصة «شخّصني» (Shakhesni Platform) 🌟
### المنصة المؤسسية الموحدة لإدارة طلبات وتشخيص الطلاب ذوي الإعاقة

نظام رقمي وطني شامل لإدارة رحلة تشخيص الطلاب ذوي الاحتياجات الخاصة والموهوبين في المملكة العربية السعودية، بدءاً من تقديم الطلب من المدرسة أو ولي الأمر، مروراً بمراجعة الوثائق الطبية، وجدولة المواعيد ومنع التعارض، وتطبيق المقاييس الإكلينيكية المعيارية، وبناء الخطة التربوية الفردية (IEP)، وحتى الاعتماد بالختم الرقمي والتسليم والأرشفة.

---

## ✨ المميزات الرئيسية (Core Features)

- 🔄 **محرك الحالات التشغيلية الصارم (State Machine Engine):** إدارة 10 حالات متسلسلة للطلب مع منع الانتقالات العشوائية.
- ⏱️ **حاسبة اتفاقية مستوى الخدمة الذكية (Smart SLA Calculator):** تتبع دقيق لأيام المعالجة مع إيقاف مؤقت تلقائي أثناء انتظار الوثائق.
- 🩺 **مساحة التقييم والتشخيص الإكلينيكي (Diagnostic Workspace):** مكتبة مقاييس معتمدة (WISC-V, SB-5, GARS-3, Vineland-3, Conners-3) مع حساب تلقائي للدرجات المعيارية والمئينية والمجالات الفرعية.
- 🎓 **باني الخطة التربوية الفردية التفاعلي (IEP Hub & Progress Tracker):** صياغة أهداف SMART المقاسة وتتبع نسب الإنجاز والإتقان.
- 💬 **مركز مراسلات أولياء الأمور (SMS & WhatsApp Multi-Channel Hub):** إرسال إشعارات رسمية موثقة لولي الأمر مع محاكي هاتف ذكي مباشر.
- 🤖 **مساعد الذكاء الاصطناعي المساند (AI Copilot):** فحص المستندات بالـ OCR، كشف التناقضات بين المنزل والمدرسة، واقتراح التوصيات التربوية.
- 🛡️ **الاعتماد والختم الرقمي وبوابة التحقق بالـ QR:** إصدار وثيقة رسمية A4 مع بصمة SHA-256 ورمز QR يوجه لبوابة التحقق العامة.
- ⌨️ **لوحة الأوامر والتنقل السريع الفائق (Command Palette - `⌘K`):** بحث لحظي في كافة الصفحات والطلبات والطلاب.
- 📱 **تطبيق ويب تقدمي (PWA & Offline Service Worker):** جاهز للعمل والتثبيت على أجهزة الآيباد والجوال للأخصائيين الميدانيين.

---

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend & Backend:** Next.js 15 (App Router), React 19, TypeScript
- **Styling & UI:** Tailwind CSS, Lucide Icons, next-themes (Light & Dark Mode)
- **Database & Security:** PostgreSQL 16 / Supabase with Row Level Security (RLS)
- **Containerization:** Docker (Multi-stage build), Docker Compose
- **State Management:** Reactive Store Context with Audit Logging

---

## 🚀 التشغيل والتثبيت محلياً (Quick Start)

### المتطلبات:
- Node.js 20+
- npm أو yarn

### خطوات التشغيل:
```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev -- -p 3010

# 3. فتح التطبيق في المتصفح
# http://localhost:3010
```

---

## 🐳 التشغيل باستخدام Docker:
```bash
# تشغيل التطبيق وقاعدة بيانات PostgreSQL بضغطة زر
docker-compose up --build -d
```

## 📁 هيكلية المشروع (Project Structure)
```
├── app/                        # مسارات وواجهات Next.js App Router
│   ├── analytics/              # لوحة المؤشرات الإحصائية والـ BI
│   ├── appointments/           # إدارة المواعيد ومصفوفة الحضور
│   ├── diagnostic-workspace/   # مساحة التقييم الإكلينيكي وحاسبة المقاييس
│   ├── iep/                    # باني الخطة التربوية الفردية SMART
│   ├── reports/                # التقرير التشخيصي الرسمي المعتمد A4
│   ├── requests/               # إدارة وسجل طلبات التشخيص الموحدة
│   └── verify/                 # بوابة التحقق الرقمي العامة بالـ QR
├── components/                 # المكونات المشتركة ولوحة الأوامر ⌘K
├── docs/                       # التوثيق الهندسي ودليل المستخدم وAPI
├── lib/                        # محرك الحالات، RBAC، وحاسبة الـ SLA
├── public/                     # أصول PWA وملف الـ Manifest و Service Worker
├── supabase/                   # مخططات وقواعد بيانات PostgreSQL والـ Migrations
└── types/                      # تعريفات TypeScript ونماذج البيانات
```
